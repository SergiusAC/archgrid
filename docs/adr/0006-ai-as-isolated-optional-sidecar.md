# ADR-0006. AI — изолированный отключаемый sidecar, предлагающий команды

- **Статус:** accepted
- **Дата:** 2026-08-17

## Контекст

AI Copilot — существенная часть ценностного предложения (text → diagram, review, semantic search, impact analysis). При этом продукт поставляется on-prem, доступ к LLM плагинуемый: внешний API, Azure OpenAI или локальная модель. В части контуров AI будет отключён политикой безопасности либо недоступен физически (air-gap).

## Решение

AI реализуется как отдельный Python-сервис (FastAPI) со следующими нерушимыми ограничениями:

1. **Нет доступа к базе данных.** Ни на запись, ни на чтение, ни для эмбеддингов.
2. **Полностью stateless.** Вход: JSON с фрагментом модели, релевантной частью метамодели и запросом. Выход: JSON с **предлагаемыми командами изменения модели**.
3. **Команды применяет Java** — через тот же конвейер, что и ручные правки (ADR-0004): authz, валидация по метамодели, коммит.
4. **Продукт полностью функционален при выключенном AI.** Флаг на уровне workspace, не сборочный флаг.
5. Провайдер LLM за портом `LlmProvider`: OpenAI-совместимый endpoint (покрывает Azure OpenAI, vLLM, Ollama) и Claude API. Конфигурируется заказчиком.

## Обоснование

- **Ошибочное предложение LLM физически не может испортить модель**: оно проходит ту же валидацию, что и действие пользователя. Это снимает основной риск AI-фич в инструменте, от которого ждут корректности.
- Изоляция от БД устраняет целый класс вопросов на техаудите заказчика — куда уходят данные и что видит модель.
- Отключаемость — требование рынка, а не запасной вариант.
- Абстракция провайдера сохраняет актив (промпты, схемы ответов, эвристики) и не создаёт привязки к вендору.

## Дополнительно

- Все результаты AI — предложения с явным подтверждением пользователя. Автоматической записи в модель нет ни в одном сценарии.
- Обход графа для impact analysis выполняет Java; LLM только формулирует последствия человеческим языком. Не отдавать LLM то, что детерминированно вычисляется.
- Embedding-модель для semantic search должна работать локально в сайдкаре, иначе semantic search недоступен в air-gap.

## Последствия

- Второй рантайм в on-prem-поставке. Оправдан тем, что он опциональный и его отсутствие не ломает систему.
- Требуется контрактное тестирование границы Java ↔ Python.
- Первая строка Python-кода пишется в фазе 7, не раньше.
