# Спайк: библиотека канваса

Доказательная база для [ADR-0010](../../docs/adr/0010-canvas-library.md). Одна и та же сцена,
собранная на JointJS core и на maxGraph, чтобы решение принималось по факту, а не по описанию
на сайте библиотеки.

Сцена подобрана так, чтобы каждое требование было видно глазом: контейнер с вложенным
элементом; пара, выровненная по горизонтали; пара, выровненная по вертикали; две диагонали,
пересекающиеся посередине; овал сервиса; метки на связях.

```bash
cd spike/canvas
npm install
npm run dev
# http://localhost:5199/joint.html
# http://localhost:5199/maxgraph.html
```

Каждая страница печатает под канвасом список проверок. Снимки — `build/ui-check/spike-*.png`.

Две ловушки, на которые спайк уже попался и которые стоит помнить, если будете его править:

- **Перескок рисуется кубической кривой, а не дугой.** Проверка на `A`/`a` в пути даёт ложное
  «нет».
- **maxGraph рисует наконечники стрелок отдельными путями того же цвета,** и они многосегментные.
  Проверка «в пути больше одного `L` — значит перескок» даёт ложное «да»: считать нужно только
  пути длиной больше 100px.

Каталог не входит в сборку продукта и держится ровно до тех пор, пока живы утверждения ADR-0010.
